==============================================================================
  VERITROOPER EVALUATION SUITE
==============================================================================

This is the separate, limited edition of VERITROOPER for product evaluation.
It includes Scout, SitRep, and Watchtower. Governance Records is included as a
supporting workflow so you can carry real audit evidence through human review.

WHAT THE LIMIT MEANS
-------------------

  Total runs             5, shared across Scout, SitRep, and Watchtower
  Per-run ceiling        200 questions or evaluated interactions
  Time limit             14 days from the first real audit

Opening the app, configuring connections, creating a Watchtower deployment, or
using Governance Records does not spend a run. A Scout or SitRep audit spends
one run when it begins. Watchtower spends one run for each cycle that actually
has captured conversations to audit.

All three audit tools draw from the same five-run allowance. For example, two
Scout audits, one SitRep audit, and two Watchtower cycles use all five runs.
The paid VERITROOPER Audit Suite is a separate installation and is unlimited.

INSTALLING AND STARTING
-----------------------

Keep Setup.exe and every numbered Setup .bin file together in one folder.
Double-click VERITROOPER Evaluation Suite Setup.exe and follow the prompts.
Then open the VERITROOPER Evaluation shortcut on the desktop.

The evaluation starts air-gapped, using the bundled local model. If you choose
a cloud model or endpoint, data sent to that provider is governed by that
provider's terms and uses your own key. VERITROOPER sends no audit data to us.

RESULTS AND SUPPORT
-------------------

Results are written under your Documents folder. Evaluation reports are marked
TRIAL VERSION. Keep completed evidence packages if you later install the paid
edition; installing the paid edition does not require deleting prior work.
